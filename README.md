# Линейная регрессия и регуляризация

## О проекте

В этом проекте я разбирался с линейной регрессией и её применением для предсказания стоимости аренды квартир.

Основная задача — реализовать алгоритмы обучения линейной регрессии самостоятельно, попробовать разные способы оптимизации и сравнить модели с регуляризацией и без неё.

Также я исследовал данные, обработал признаки и сравнил результаты моделей с помощью нескольких метрик качества.

## Данные

Датасет

Для работы использовался датасет объявлений об аренде квартир из соревнования [Two Sigma Connect: Rental Listing Inquiries на Kaggle](https://www.kaggle.com/competitions/two-sigma-connect-rental-listing-inquiries/data).

В проекте я использовал файлы `train.json` и `test.json`. Датасет не хранится в репозитории, поэтому для повторения экспериментов его нужно скачать по ссылке выше.

Целевая переменная — `price`, то есть стоимость аренды квартиры.

В качестве признаков использовались:
- `bathrooms` — количество ванных комнат;
- `bedrooms` — количество спален;
- характеристики квартир из поля `features`, например наличие лифта, посудомоечной машины, тренажёрного зала и других удобств.

Перед обучением я обработал список характеристик и преобразовал наиболее распространённые из них в отдельные бинарные признаки.

## Что было сделано

### 1. Исследование данных

- Изучил структуру датасета и основные характеристики признаков.
- Посмотрел, какие удобства чаще всего встречаются в объявлениях.
- Проанализировал распределение стоимости аренды.
- Обработал выбросы с помощью квантилей.
- Подготовил признаки для обучения моделей.

### 2. Реализация линейной регрессии

Я реализовал собственный класс `MyLinearRegression`, в котором предусмотрел три способа обучения:

- **Аналитическое решение** — вычисление весов с помощью псевдообратной матрицы.
- **Градиентный спуск (GD)** — последовательное обновление весов на основе градиента функции потерь.
- **Стохастический градиентный спуск (SGD)** — обучение с использованием небольших случайных пакетов объектов.

Это позволило разобраться в том, как происходит обучение линейной модели и как выбор метода оптимизации влияет на результат.

### 3. Регуляризация

Также я реализовал линейную регрессию с регуляризацией:

- **Ridge (L2)** — добавляет штраф за большие значения весов.
- **Lasso (L1)** — может обнулять веса отдельных признаков.
- **ElasticNet** — сочетает L1- и L2-регуляризацию.

Я сравнил результаты моделей с разными вариантами регуляризации и посмотрел, как они влияют на качество предсказаний.

### 4. Масштабирование и преобразование признаков

В ходе экспериментов я попробовал:

- `StandardScaler` — стандартизацию признаков;
- `MinMaxScaler` — масштабирование признаков в заданный диапазон;
- `PolynomialFeatures` — создание полиномиальных признаков для моделирования нелинейных зависимостей.

Отдельно проверил, как изменение признаков и их масштаба влияет на качество моделей.

### 5. Оценка качества

Для сравнения моделей использовал следующие метрики:

- **MAE** — средняя абсолютная ошибка предсказания.
- **RMSE** — корень из среднеквадратичной ошибки.
- **R²** — коэффициент детерминации, показывающий, насколько хорошо модель объясняет изменчивость целевой переменной.

## Результаты

В экспериментах сравнивались обычная линейная регрессия, Ridge, Lasso и ElasticNet, а также разные способы масштабирования признаков.

Некоторые результаты на тестовой выборке:

| Модель | MAE | RMSE |
|---|---:|---:|
| Линейная регрессия, SGD | 716.43 | 1226.84 |
| Ridge | 731.77 | 1152.56 |
| ElasticNet | 720.30 | 1168.61 |
| Линейная регрессия с StandardScaler | 717.83 | 1230.26 |
| Ridge с StandardScaler | 717.16 | 1207.19 |
| Линейная регрессия с MinMaxScaler | 756.01 | 1125.74 |

В экспериментах результаты зависели от выбранного метода обучения и масштабирования. Например, обычная линейная регрессия с SGD показала MAE около 716, а вариант с MinMaxScaler — RMSE около 1126.

Полиномиальные признаки степени 10 не дали хорошего результата: значение R² на тестовой выборке оказалось отрицательным. Это показывает, что усложнение модели не всегда улучшает предсказания.
